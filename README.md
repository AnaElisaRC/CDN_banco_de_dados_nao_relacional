🍃 Banco de Dados Não Relacional

Este repositório reúne as atividades práticas desenvolvidas na disciplina de Banco de Dados Não Relacional do curso de Tecnologia em Ciência de Dados para Negócios da FATEC Votorantim.

O conteúdo abrange conceitos e práticas com MongoDB, incluindo estruturação de documentos NoSQL, consultas avançadas com o operador `find`, contagem de documentos e construção de pipelines de agregação.
